# Research and historical evidence

This tree preserves reproducible evidence behind the clean-room SDK without
mixing it into the supported application surface.

- `notes/`: dated subsystem reconstruction notes.
- `reports/`: metadata-only catalogs generated by `tools/re/`.
- `probes/`: one-off or superseded experiments.
- `archive/`: early documentation and historical source material.

Use the current `docs/` site and public headers when building an application.
Research notes may contain role-specific observations and unresolved theories;
they do not override current targets, APIs, tests, or the capability matrix.

New evidence should include the command, relevant input hashes, environment,
and observed result without copying retail executable bodies or assets.
