# Research archive

This directory preserves the evidence behind the clean-room SDK without
mixing it into the supported development surface.

- `research/notes/` contains subsystem reconstruction notes.
- `research/reports/` contains reproducible metadata-only catalogs.
- `probes/` contains one-off or superseded experimental programs.
- `archive/` contains early documentation and historical source material.

New game code should use `app/`, `include/`, `src/`, and `examples/` instead.

The motion-sensor reconstruction is documented in
[`notes/16_motion_accelerometer.md`](notes/16_motion_accelerometer.md).
