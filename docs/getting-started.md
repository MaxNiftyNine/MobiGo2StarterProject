# Getting started has moved

Use the maintained [installation guide](start/install.md), then
[build and run the first project](start/first-project.md).

The canonical commands are `python3 tools/mobigo.py doctor` and
`python3 tools/mobigo.py run`. New projects target SY; G1 is a legacy explicit
opt-in described under [Target profiles](start/target-profiles.md).
