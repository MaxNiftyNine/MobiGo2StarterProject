# Archived manuals

These PDFs are preserved as primary or historical reference material. They do
not override the maintained SDK API, target defaults, or tested workflows in
this site.

- [MobiGo 2 Programmer's Guide (PDF)](mobigo2_programmers_guide.pdf) records
  the earlier reverse-engineering and application-development work. Use the
  current guides for commands and compatibility claims.
- [Generalplus GPL16250VA data sheet (PDF)](GPL16250VAV10_ds.pdf) documents the
  SoC family and peripheral register model. Device-specific behavior still
  requires MobiGo 2 evidence.
- [u'nSP 2.0 instruction reference (PDF)](unsp2.0.pdf) documents the processor
  instruction set used when inspecting or writing target assembly.
